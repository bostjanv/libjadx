# LibJadx 0.1.0-alpha.1 — draft release notes

First public candidate, experimental alpha. **NOT PUBLISHED**; no tag or release
has been created. The API may change before 1.0. Fresh qualification reports
belong under `docs/release-evidence/0.1.0-alpha.1/`; publication requires the
separate [publication checklist](../alpha-publication-checklist.md).

## Highlights

- Standalone headless Jadx 1.5.6 service with a versioned REST/JSON OpenAPI contract.
- Python synchronous/asynchronous SDK with generated typed transport.
- Native `.jadx` persistence with explicit save, conflict detection and reload.
- Original class/member identities, decompiled Java, basic references and incremental search.
- Heavy jobs with polling, progress and SSE.
- Supported declaration renames and LINE comments, strict Tiny v2 mapping import/export.
- Conservative snapshot-bound parameter renames and partial related-method propagation.

## Important limitations

The service assumes trusted local clients and files: it binds to loopback, has
no authentication and serves exactly one fixed project per process. Qualification
targets Linux x86_64 with JDK 21 and CPython 3.11/3.14; Windows/macOS execution
is unqualified. Bundled input plugins do not imply qualification of every format.

There is no public Smali representation, CFG or resource-query API. Local-variable
rename is unsupported. References and related propagation are partial. Primary
Jadx reads are serialized; conflicting requests fail `PROJECT_BUSY`. Cancellation
is cooperative and does not guarantee interruption of arbitrary JVM work.
